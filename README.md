
# Face Mask Classification using CNN

This project uses a Convolutional Neural Network (CNN) to classify whether a person is wearing a face mask or not. The model can be tested with uploaded images and is also compatible with webcam input when deployed using Gradio.

---

## 🎯 Project Goal

To build an automated deep learning model that helps identify whether an individual is wearing a mask, which can be useful in health monitoring and public safety scenarios.



## 🧠 Model Summary

- **Model Type:** Convolutional Neural Network (CNN)
- **Framework:** TensorFlow / Keras
- **Output Classes:**  
  - With Mask  
  - Without Mask

---

## 📈 Performance

The trained model achieved strong classification accuracy based on evaluation metrics and testing using unseen images.
